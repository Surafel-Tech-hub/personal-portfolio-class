# Personal Portfolio Website

## 1. Project Overview

This project is a personal portfolio website developed to introduce myself, present my skills and educational background, showcase my projects and achievements, and provide a way for visitors to contact me.

The website is designed with a modern, responsive layout that works on desktop, tablet, and mobile devices. It provides a central place to learn about my background, explore my work, and connect with me.

## 2. Technologies Used

The project was developed using the following technologies:

- **HTML5:** Used to structure the website and organize its content into different sections.
- **CSS3:** Used for styling, layout, responsive design, animations, transitions, and visual effects.
- **JavaScript:** Used to add interactivity and dynamic functionality to the website.
- **Git and GitHub:** Used for version control and project hosting.

No frontend framework was used. The website was built using plain HTML, CSS, and JavaScript.

## 3. Main Features

The website includes the following features:

### Home Section
- Introduces me with a short personal introduction.
- Provides navigation to other sections of the website.

### About Section
- Presents my background and interests.
- Includes information about my education and personal goals.

### Skills Section
- Displays my technical skills, including HTML, CSS, JavaScript, Git, and GitHub.
- Highlights soft skills such as problem-solving, teamwork, communication, and time management.

### Projects Section
- Showcases selected projects, including:
  - ET Tour
  - Hustle Gym Landing Page
  - Rock–Paper–Scissors Game
- Provides links to explore the projects.

### Infinite Spiral Gallery
- Displays project-related images in an animated 3D spiral layout.
- Includes automatic movement and pauses when the user hovers over the gallery.

### Education Section
- Displays my academic background and educational information.

### Achievements Section
- Showcases certificates earned from Udacity.
- Allows visitors to click certificate previews to view the full certificates.

### Contact Section
- Provides a contact form for visitors to send messages.
- Includes email and other contact information.
- Uses Formspree to process contact form submissions.

### Additional Website Features
- Responsive navigation menu for smaller screens.
- Dark and light theme switching.
- Active navigation links based on the current section.
- Scroll-reveal animations for page elements.
- Animated loading screen when the website opens.
- Automatic updating of the copyright year in the footer.

## 5. How to Run the Project

The website is built with HTML, CSS, and JavaScript, so it does not require a backend server or package installation to display locally.

Follow these steps:

1. Download or clone the project repository from GitHub.
2. Extract the project folder if it was downloaded as a ZIP file.
3. Open the project folder using Visual Studio Code.
4. Make sure the project files and folders are in their correct locations.
5. Open `index.html` in a web browser.

### Recommended Method: Using Live Server

1. Open Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Open the project folder in Visual Studio Code.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The website will open in your default browser.

## 6. Contact Form

The contact form uses Formspree to process messages submitted by visitors. When a visitor completes the form and submits it, the message is sent to the configured email address.

An internet connection is required for contact form submissions.
